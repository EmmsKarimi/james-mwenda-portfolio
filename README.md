# James Mwenda — Executive Portfolio

An executive web portfolio for **James Mwenda** (Senior Tax & Finance Executive, CPA-K, PhD Candidate in Economics), highlighting 13+ years of leadership, policy engagements, and published tax research.

## Features
- **Executive Leadership Overview:** Summary of strategic leadership, financial systems architecture, and board advisory experience.
- **Policy & Research:** Key tax submissions, Legislative commentary, and academic research publications.
- **Direct Resource Links:** Quick links to peer-reviewed publications, research papers, and policy contributions.
- **Responsive Layout:** Designed for desktop and mobile devices.

## Tech Stack
- **Framework:** React / Vite / TypeScript
- **Styling:** CSS / Tailwind CSS
- **Design:** Figma

## Running Locally

1. Navigate into the project folder:
```bash
cd "Executive Portfolio Website Design"

```


2. Install dependencies:
```bash
npm install

```


3. Start the development server:
```bash
npm run dev

```
